Rules for the JSON:
- `form` is exactly "tú" or "usted" (this book is tú/usted only — no voseo).
- Every non-empty direction MUST end with exactly one `{ "form": ..., "when": "default" }`
  rule so any scene resolves; put more specific `when` rules (public/private/…)
  BEFORE the default, in priority order.
- Keep `content` self-contained and human-readable: it is what the judge reads.
- NAMING: if the <characters> block above lists an approved cast, use those
  target-language names exactly. If it says no cast list exists yet, use the
  ENGLISH source names exactly as they appear in the sample chapters. Never
  invent a target-language name — the glossary has not fixed them yet, and a
  guess it later contradicts leaves the judge reading names that never appear
  in the prose.
- Output ONLY the JSON object, no commentary, no code fences.

Rules for `style_guide_summary` — read this carefully, it has a different reader
than everything else here:

`content` is read by a judge that can see the whole picture. `style_guide_summary`
is folded into the style guide, which is handed to a translator working on ONE
excerpt of the book. That translator does not know which chapter the excerpt is
from, what happened before or after it, or that this map exists. So:

- 60–90 words. Prose or short lines, no JSON, no headings.
- State the GENERAL rules first — the ones that resolve most scenes (who uses
  usted with whom by role: children/adults, servants/employers, strangers, etc.).
- Then name ONLY the high-frequency pairs that are EXCEPTIONS to those general
  rules. A pair that simply follows the general rule must not be named.
- Do NOT reproduce the pair list. If you find yourself naming more than two or
  three pairs, your general rules are not general enough.
- NEVER reference a chapter number, "later in the book", "once they marry", "as
  the story progresses", or "the address map" itself. A rule the translator
  cannot apply from the excerpt in front of them is worse than no rule: write the
  form that holds for most of the book and omit the transition entirely.
- Write it as instructions to the translator, not as a description of the book.
